🏢 Contexto
Uma organização precisa informatizar um processo atualmente realizado
manualmente.
Sua equipe deverá atuar como uma empresa de desenvolvimento e propor
uma solução para esse problema.



**Tema: Controle de Estoque de Cafeteria**



1\. Identificação do Projeto

* Nome do sistema - StockSmart (S\&S)
* Nome dos integrantes - Pedro, José
* Descrição do problema - Criar um sistema que organize o estoque de uma cafeteria respeitando o atual sistema do estabelecimento
* Objetivo da solução - Tornar a administração de estoque da empresa mais prático e simples



2\. Levantamento de Requisitos



Exemplos:

=> Requisitos Funcionais <=

* Cadastrar usuário
* Consultar registro
* Atualizar informações
* Excluir registro
* Gerar relatório

\-

OBS: Mínimo - 5 requisitos funcionais



=> Requisitos Não Funcionais <=

* Facilidade de uso
* Organização dos dados
* Facilidade de manutenção
* Validação das informações

\-

OBS: Mínimo - 3 requisitos não funcionais

\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_



=> Requisitos Funcionais (Deve ser possível) <=

* Deve ser possível cadastrar produtos(nome, quantidade, preco, data\_validade)
* Deve ser possível alterar a quantidade do produtos
* Deve ser possível encontrar um produto especifico(nome ou ID)
* Deve ser possível ordenar produtos por preço, data de validade
* Deve ser possível filtrar produtos vencidos



=> Requisitos Não Funcionais (Não Deve ser possível) <=

* O sistema deve carregar as páginas em até 3 segundos em condições normais de uso
* O sistema deve apresentar uma interface simples e intuitiva, permitindo que novos usuários compreendam suas principais funções sem treinamento
* O sistema deve estar disponível 99% do tempo, exceto durante manutenções programadas
